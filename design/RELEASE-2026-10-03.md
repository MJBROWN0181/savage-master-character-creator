# Savage Master — Character Creation & Gilded Storybook Preview

Players can now choose Savage Worlds, D&D, or Pathfinder from a dedicated three-card entry page and build a character one decision at a time. Each game keeps its own rules, with a live character preview, a checked chapter timeline, and automatic return to the top when changing sections.

## Included

- Game-specific skills, feats, spells, attributes, purchases and choice limits, with Bug explaining missing requirements and offering the next step.
- D&D multiclass eligibility, independent spell sources and preparation limits, skipped spell steps for noncasters, and species language grants with bounded language choices.
- Game-specific equipment shopping followed by name and biography, with a reviewed prompt helper for ChatGPT biographies and portrait creation.
- Unique Gilded Storybook illustrations for all game, setting, species, class and heritage cards. Original PNGs, optimized WebP exports, full prompts and the canonical style guide are preserved.
- Compact background title cards with subtle teal-and-gold decoration, searchable names, Greater Detail and game-specific bonuses.
- Separate game routes and responsive detail windows with accessible confirmation controls.

## Validation

The isolated release passed 187 tests (75 Vitest and 112 Node), TypeScript checking, the production build and whitespace checks. The image audit found 212 unique preserved exports, no missing files, no duplicate images and no pending illustration work. Four existing background portraits are retained as source history; background choices now use decorative titles.

Pathfinder remains a preview with table review for conditional features and uncommon options. Existing catalogue-size and classic-script build warnings remain. This release includes character creation; separate unfinished community, account-settings and Bug companion work stays in the development checkout.
