# Savage Master original artwork

Generated with the built-in image-generation tool. Transparent PNG originals are in `art-source/`; alpha-preserving, 720 × 480 WebP web assets are in `../images/art/`. Originals are excluded from the production static copy; only the small WebP assets ship.

The set connects three moments: create a hero, prepare the next adventure, and keep shared memories. Antique gold, forest teal, leather, parchment, and etched watercolor details complement the existing theme. The illustrations are decorative (`alt=""`) because surrounding headings explain the purpose. No existing franchise art, logos, or recognizable characters were requested. Artwork never replaces account avatars or user backgrounds.
