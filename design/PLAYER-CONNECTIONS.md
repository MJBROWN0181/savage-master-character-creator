# One profile, every game

Profiles are indexed uniquely by account owner, with player and GM roles on the same record. Game interests are freeform profile fields; character favorites accept owned characters from both systems. Game switches and campaigns link to the same `/profile` route.

Friends are account-to-account connections independent of character, campaign, and game. Send requests by reviewed public profile handle or directly from a shared public profile. Only the recipient can accept/decline. Friends and pending requests are visible only to participants. Responses use reviewed names, games, and avatars, never private drafts. Friendship grants no character, journal, scene, or campaign permissions.

Both users need approved public profiles to initiate requests. Requests are limited to 20 outstanding and 20 per day, with a seven-day cooldown after decline/cancel/removal. Either player can remove a connection or block requests. Blocking hides connections from both parties and ends existing requests/friendships. Only the block owner can unblock, including when the other profile becomes private. This blocks friend requests, not access to a publicly shared profile.

Campaign party entries link to reviewed shared profiles. Private/unreviewed profiles expose no handle. Existing moderation, age attestation, and reporting remain required for public profiles. There is no automatic friendship, public friend directory, or direct messaging.
